<h2>Date Picker and Date Range Picker for Unity, made in UI Toolkit.</h2>

![alt text][logo]

[logo]: /RepoResources/range-picker-screenshot.png "Date Range Picker Sample"

<b>
Customizable UI Toolkit DatePicker and DateRangePicker controls for Unity. Supports single or range date selection, callbacks, and programmatic control.
</b>
<br>
<br>
The package provides two fully functional and customizable UI Toolkit controls: DatePicker for single-date selection and DateRangePicker for start–end date ranges.

Both UI Toolkit components follow standard UI Toolkit patterns, making them easy to integrate into your existing layouts. You can style them via USS and UXML, or control them entirely through C# scripts.
